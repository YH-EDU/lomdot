# לומדה · זמן התפילין ויד שמאל — סוגיות ו–יא

לומדה לחזרה עצמית על סוגיות ו–יא (מנחות לו ע״ב – לז ע״א), לכיתה ז׳.

**קישור ללומדה:** https://yh-edu.github.io/lomda-tefillin-sugyot-6-11/

- כניסה עם שם — ההתקדמות נשמרת בדפדפן.
- תזכורת עם לשון הגמרא לפני כל סוגיה; לחיצה על מילה בארמית מציגה את התרגום.
- סוגי שאלות מגוונים: רב־ברירה, נכון/לא נכון, מחסן מילים, התאמה, מיון, סידור, כתיבה, ומשחקי ארמית.
- אפשר לחזור כמה פעמים — השאלות מתערבבות מחדש בכל ניסיון; רמז 💡 וניסיון שני בחצי נקודות.
- קובץ אחד (`index.html`) שעובד גם בלי אינטרנט, בלי גופנים או ספריות חיצוניים.

קובצי המקור נמצאים בתיקייה `src/`.
