# לומדות · YH-EDU

מאגר אחד לכל הלומדות. כל לומדה נמצאת בתיקייה משלה, ודף הבית (`index.html`) מציג את כולן ככרטיסים.

**דף הבית:** https://yh-edu.github.io/lomdot/

| לומדה | קישור קבוע |
|---|---|
| זמן התפילין ויד שמאל — סוגיות ו–יא (מנחות לו ע״ב – לז ע״א) | https://yh-edu.github.io/lomdot/tefillin-sugyot-6-11/ |

## איך מוסיפים לומדה
1. יוצרים תיקייה חדשה עם שם באנגלית (למשל `berachot-perek-1`) ושמים בה `index.html`.
2. מוסיפים כרטיס בדף הבית (`index.html` שבשורש) ושורה בטבלה כאן.

כל לומדה היא קובץ אחד שעובד גם בלי אינטרנט: אין בה גופנים או ספריות חיצוניים (מתאים לנטספארק). קובצי המקור של כל לומדה נמצאים בתיקיית `src/` שלה.
